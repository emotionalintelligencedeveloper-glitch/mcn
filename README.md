Open-Source Emotional Wellbeing Tools

We create free emotional wellbeing tools because support should never be locked behind a paywall.

This repository contains open-source tools designed to help people pause, reflect, regulate emotions, and feel more grounded during difficult moments.

Every day, people visit our platform looking for clarity, calm, and emotional strength. We keep these tools accessible to everyone — regardless of income or background.

Why This Exists

The world is changing fast. Technology is evolving. Pressure is increasing.

We believe emotional support tools should remain accessible and adaptable as the world continues to change.

This project exists to:

Promote emotional intelligence

Support mental wellbeing

Provide practical self-help tools

Keep wellbeing resources open and free
