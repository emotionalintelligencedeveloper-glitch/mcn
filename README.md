## Open-Source Emotional Wellbeing Tools

We create free emotional wellbeing tools because support should never be locked behind a paywall.

This repository contains tools designed to help people pause, reflect, regulate emotions, and feel more grounded during difficult moments.

Every day, people visit our platform looking for clarity, calm, and emotional strength. We keep these tools accessible to everyone, regardless of income or background.

🌍 **Website:** https://emotionalintelligencedeveloper.com

🧰 **All tools, live:** https://emotionalintelligencedeveloper.com/wellbeing-and-self-help-tools/

🤝 **Community Support:** https://members.emotionalintelligencedeveloper.com

---

## How to Use These Tools

Each tool is a single HTML file. There is nothing to install.

1. Download the file you want, or clone this repository.
2. Open the file in any web browser.

You can also use all of them online at the tools page above.

## A Note on Safety

These tools are for reflection and self-support. They are not a replacement for professional help. If you or someone near you is in danger or in crisis, please contact your local emergency number or a local crisis line right away.

## Why This Exists

The world is changing fast, and pressure is increasing. We believe emotional support tools should remain accessible and adaptable.

This project exists to:

- Promote emotional intelligence
- Support mental wellbeing
- Provide practical open-access self-help tools
