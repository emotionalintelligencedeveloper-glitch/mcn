How it works

  1. Headline Round: submit headline ideas and vote. First headline to 10 votes becomes the chosen headline.
  2. Story Build Round: submit candidate snippets (max 210 chars). First snippet to 10 votes wins the round and is appended.
  3. One winner each round: all other candidates in that round are marked “Not selected this round.”
  4. Publish gate: story publishes only at 396+ words.
  5. Share to get votes: each headline/snippet has a share button for vote links.

Deploy steps (GitHub Pages)

  1. Create a new repo named eid-community-story-game in your GitHub account.
  2. Add this file as index.html at the repository root.
  3. Commit and push.
  4. In GitHub repo settings → Pages, set source to Deploy from branch, branch main / root.
  5. Your site URL format: https://YOUR-USERNAME.github.io/eid-community-story-game/

Real-time setup

Paste your Firebase web config in the CONFIG SECTION near the top of the script. If blank, app runs in Demo Mode (localStorage only).
