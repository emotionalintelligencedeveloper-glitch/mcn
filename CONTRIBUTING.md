# 🎯 What This Project Is

Our tools help people pause, reflect, regulate emotions, and feel more grounded. They are free because support should never be locked behind a paywall.

Most tools are single, self-contained HTML files that anyone can open in a browser. The repository also includes the EID Community Story Game, a real-time collaborative writing experience built with Firebase.

# 🛠 Ways You Can Contribute

### Improve an existing tool
- Mobile layout and responsiveness
- Accessibility (screen readers, keyboard use, contrast, text size)
- Clearer wording and easier language
- Bug fixes

### Suggest or add a new tool
- Open an Issue first and describe the idea and who it would help
- Wait for a reply before you build it

### Story Game
- Firebase stability and reconnection handling
- Voting synchronization
- Moderation tools
- Story archive and PDF reliability
- Abuse prevention

### Documentation and community
- Clearer instructions
- Bug reports and accessibility feedback
- Translations (open an Issue first so we can plan them well)

# 📌 Contribution Process

1. Fork the repository
2. Create a new branch with a clear name
3. Make your changes
4. Test them in a real browser, including on a phone screen
5. Submit a pull request that explains:
   - what you changed
   - why you changed it
   - any tradeoffs or concerns

Please keep your work readable, simple, and well commented.

---

# 🧩 Guidelines for Tools

- Keep each tool as **one self-contained HTML file** where possible.
- Match the look and feel of the existing tools.
- Use plain, kind, easy-to-understand language.
- Make sure it works on small phone screens.
- Keep it accessible: labels on inputs, good contrast, usable with a keyboard.
- Do not add heavy libraries when simple code will do.
- Keep the credit footer and the "not medical or crisis advice" wording on every tool.

---

# 💛 Care, Safety and Wellbeing Content

Some tools deal with sensitive topics such as suicide, domestic violence, addiction, grief, and violence. Please take extra care.

- **Never** present a tool as medical advice, a diagnosis, or a treatment.
- Do not change crisis wording, safety guidance, or helpline details unless you have checked that your change is accurate and safe. Include your source in the pull request.
- Do not add content that could shame, pressure, or scare someone who is struggling.
- Avoid promising results.
- If you are not sure, ask in an Issue first.

---

# 🔒 Privacy

Our tools tell people that what they write stays on their own device and is not saved or sent anywhere. That promise matters.

Do **not** add any of the following without opening an Issue and getting agreement first:

- Analytics or tracking
- Cookies or local storage of personal answers
- Forms or code that send user answers anywhere
- Third-party scripts, ads, or embeds

---

# 🔐 Security Guidelines (Story Game and Firebase)

The Story Game uses Firebase (Firestore and Authentication).

Contributors must NOT:

- Remove validation safeguards
- Add unrestricted database writes
- Expose secrets or tokens
- Remove abuse protections
- Change Firebase project configuration without discussion
- Add unsafe third-party scripts

### Reporting a security problem

If you find a security problem, please **do not post it in a public Issue**. Report it privately instead, through GitHub's private vulnerability reporting (the **Security** tab of this repository) or through the contact details on https://emotionalintelligencedeveloper.com. We will respond as soon as we can.

---

# 💬 Before Major Changes

Please open an Issue first if you plan to change:

- Firestore structure
- Authentication flow
- Voting systems
- Core game logic
- Moderation systems
- How a tool works at its core, or what it asks people
