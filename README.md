### Open-Source Emotional Wellbeing Tools
We create free emotional wellbeing tools because support should never be locked behind a paywall. 

This repository contains tools designed to help people pause, reflect, regulate emotions, and feel more grounded during difficult moments.

Every day, people visit our platform looking for clarity, calm, and emotional strength. We keep these tools accessible to everyone — regardless of income or background.
